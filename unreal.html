Sunset City on Unreal Engine 5

The Unreal version runs on a Windows PC: the PC's graphics card draws it. It cannot run inside a web page or on an iPad itself, but the PC can stream it to this iPad.

1. Get it on your Windows PC: one file

On the PC, open this page, download this file and double-click it.

Download SunsetCity.bat (for Windows)
  • If Windows says "Windows protected your PC", click More info, then Run anyway.
  • The first time, it sets everything up by itself. You press Yes when Windows asks, and sign in to the free Epic Games Launcher to install Unreal Engine (the window says what to click). Then it builds the game, which keeps the PC busy for an hour or two.
  • After that, the Sunset City icon on the desktop starts the game straight away, and gets new versions by itself.
  • If a step goes wrong, it leaves a note on the desktop to paste to Claude. Once it is fixed, double-click again: it carries on from there.

Needs Windows 10 or 11, a DirectX 12 graphics card (an RTX card for the best lighting), and about 100 GB free.

2. Play it on this iPad

On the PC, double-click Sunset City on iPad. Then type the address it shows here (this device must be on the same Wi-Fi as the PC):

Then tap the picture. On a touch screen a stick, a look area and buttons appear.

If nothing opens: is the window on the PC still open, is this device on the same Wi-Fi, and did Windows ask to let it through the firewall (say yes)? Then come back to this page and try again.
