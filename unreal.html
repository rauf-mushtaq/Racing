Sunset City on Unreal Engine 5

Unreal Engine cannot run inside a web page or on an iPad itself. This page connects this device to the Unreal version running on your PC: the PC's graphics card draws the game and streams the picture here (Pixel Streaming), and your touches, keys and mouse go back to it.

  1. On the PC, run Package_Windows.bat once, then Play_Streaming.bat (both are in the unreal folder of the project).
  2. Type the address it shows here (this device must be on the same Wi-Fi as the PC, or joined to it with something like Tailscale).
  3. Click or tap the picture. On a touch screen a stick, a look area and buttons appear.

If nothing opens: is Play_Streaming.bat still running on the PC, is this device on the same Wi-Fi, and did Windows ask to let it through the firewall (say yes)? Then come back to this page and try again.

This page makes no network requests itself: it only opens the address you type. Back to the web version (which runs on this device's own graphics, in the browser).
